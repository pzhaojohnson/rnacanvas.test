# Unit testing

In general, unit tests for component packages
can be run using the following command.

```
npm test
```

The `--silent` option can also be included to hide console messages
generated by tested code.

# Manual testing

## URL interface

Attempt to draw a structure using dot-bracket notation
in Chrome, Firefox and Safari browsers.

```
https://code.rnacanvas.app?sequence=AGAGUAGCAUUCUGCUUUAGACUGUUAACUUUAUGAACCACGCGUGUCACGUGGGGAGAGUUAACAGCGCCC&dot_bracket=(((((((....)))))))...(((((((((((.....(((((.......)))))..))))))))))).....
```

Check for any error messages in the console.

Check that the drawn sequences matches the one specified in the URL.
